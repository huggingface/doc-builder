class docstring_samples.SampleTokenizer

< source >

( vocab_filedo_lower_case = Trueunk_token = '<unk>'pad_token = '<pad>'**kwargs )

Parameters

  • vocab_file (str) — Path to the vocabulary file.
  • do_lower_case (bool, optional, defaults to True) — Whether or not to lowercase the input when tokenizing.

Special tokens

  • unk_token (str, optional, defaults to "<unk>") — The unknown token. A token that is not in the vocabulary cannot be converted to an ID and is set to be this token instead.
  • pad_token (str, optional, defaults to "<pad>") — The token used for padding, for example when batching sequences of different lengths.

Construct a sample tokenizer, based on a vocabulary file. Its outputs are described in SampleOutput.

Pass do_lower_case=False when the vocabulary is cased.

Example:

>>> from docstring_samples import SampleTokenizer

>>> tokenizer = SampleTokenizer("vocab.txt")
>>> tokenizer.encode("Hello world")
[7592, 2088]

Parameters

  • text (str) — The text to encode. Curly braces like {"a": 1} and angle brackets like <mask> render as text, in code and outside of it: {“a”: 1}, a token, issue #12.
  • max_length (int, optional) — Maximum length of the returned sequence. When the text is longer:
    • with truncation=True, the sequence is cut at max_length;
    • otherwise, a warning is logged.

    See decode() for the reverse operation.

  • special_tokens (dict[str, int], optional) — Special tokens to add, mapped to their ids.

Returns

list[int]

The token ids, starting with the id of <s>.

Raises

ValueError or TypeError

  • ValueError — If text is empty.
  • TypeError — If text is not a string, for example when a list of strings is passed instead of a single string.

Converts a string to a sequence of ids, using the vocabulary.
